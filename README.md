# 워터마크 컷

레드노트(小红书)에서 다시 받은 내 사진의 맨 아래 워터마크 줄을 잘라 주는 폰용 웹앱.

- `index.html` 하나로 동작해요. 서버도, 설치도 필요 없고 사진은 기기 안에서만 처리돼요.
- 기본값은 짧은 변의 8.5%(1440×1920 사진이면 아래 약 128px)를 잘라요. 레드노트 워터마크(로고 + `rednote 아이디`)가 모두 들어가는 높이예요.
- 슬라이더와 ± 버튼으로 높이를 조절하고, "워터마크 확대"로 오른쪽 아래를 크게 보며 확인할 수 있어요.
- 사진 고르기 창이 안 열리면 사진 앱에서 사진을 복사한 뒤 붙여넣기 칸에 붙여넣어도 돼요.

## 화질

- 일반 JPEG는 **다시 압축하지 않고** 잘라요. 압축된 데이터를 16px 줄 단위로 그대로 복사하고 높이 값만 바꾸는 방식이라, 남는 부분은 원본과 같은 데이터예요. 그래서 자르는 높이가 16px 단위로 맞춰져요.
- 이때 EXIF(원본 썸네일 포함), HDR 게인맵처럼 잘리기 전 모습이 남는 정보는 빼고, 색 프로필은 남겨요.
- PNG는 PNG로 저장해서 화질이 그대로예요.
- "원래 비율 유지"를 켰을 때나 프로그레시브 JPEG·HEIC·WebP 같은 파일은 품질 97% JPEG로 다시 압축해요.

## 폰 앱처럼 쓰기 (GitHub Pages)

한 번만 켜 두면 Claude 없이 `https://sogalbi.github.io/mani/` 로 바로 열려요.

1. 폰 브라우저에서 `github.com/sogalbi/mani/settings/pages` 열기
2. Build and deployment → Source: **Deploy from a branch**
3. Branch: **ccr-bc37d147-85gn25**, 폴더 **/ (root)** → **Save**
4. 1~2분 뒤 주소를 열고 Chrome 메뉴(⋮) → **홈 화면에 추가**(또는 **앱 설치**)

저장하면 안드로이드는 갤러리의 Download 앨범으로, 아이폰은 공유 시트의 "이미지 저장"으로 사진첩에 들어가요.

# 마크 찍기 (`mark/`)

스레드에 올릴 사진에 K.ASRAI 마크를 찍어 주는 폰용 웹앱. 주소: `https://sogalbi.github.io/mani/mark/`

- 위치는 잡지처럼 9칸(위·가운데·아래 × 왼쪽·가운데·오른쪽) 중에서 골라요. 미리보기 사진을 누르면 그 사진만 따로 옮길 수 있어요.
- 로고 모양: 전체 / 장식만 / 글자 가로 / 글자 세로. 크기·여백·진하기·그림자를 조절할 수 있어요.
- "마크 2개 찍기"를 켜면 두 군데에 동시에 찍어요. 위치·모양·크기는 마크마다 따로 정하고(위의 "고칠 마크"로 전환), 여백·색·진하기·그림자는 같이 써요. 처음 켜면 마크 1과 같은 로고가 반대쪽 모서리에 찍혀요.
- 색은 "자동"이면 로고 자리 배경이 밝을 때 검정, 어두울 때 흰색으로 찍어요.
- 여러 장을 한 번에 골라 같은 설정으로 저장할 수 있어요. 파일 이름은 `원래이름_kasrai.jpg`.
- 들어 있는 로고는 62×143px 원본을 키운 것이라 아주 크게 찍으면 살짝 흐려요. 설정 맨 아래 "고화질 로고 파일로 바꾸기"로 더 큰 로고(투명 PNG 또는 흰 배경 이미지)를 넣으면 이 폰에 기억해 둬요.
- 아주 큰 사진은 긴 변 4096px로 줄여서 저장해요(폰 브라우저 한도). JPEG 품질 95%.

홈 화면에 앱으로 설치: 위 주소를 열고 안드로이드 Chrome은 메뉴(⋮) → **홈 화면에 추가**(또는 **앱 설치**), 아이폰 Safari는 공유 버튼 → **홈 화면에 추가**.

# 릴스 프롬프트 (`reels/`)

인스타그램 릴스 기획용 프롬프트 7단계를 내 계정에 맞게 채워서 복사하는 폰용 페이지. 주소: `https://sogalbi.github.io/mani/reels/`

- 원문은 Threads의 aialnam 님 글(소재 찾기 → 첫 3초 후킹 → 대본 → … → 7일 테스트 일정)이에요.
- 맨 위 "내 계정"에 분야·타깃·팔로워 수·목표를 한 번 적으면 모든 프롬프트의 같은 칸에 들어가요. 주제, 아이디어, 트렌드처럼 프롬프트마다 다른 값은 각 카드에서 적어요.
- 채운 부분은 파란색, 아직 빈 칸은 노란색 `[ ]`로 보여요. "프롬프트 복사"를 누르면 채운 그대로 복사돼서 ChatGPT·Claude에 붙여넣으면 돼요.
- 적은 내용은 이 폰에만 저장돼요(서버 없음).
- 4번 프롬프트는 캡처에 담기지 않아서 비어 있어요. 원문을 카드에 붙여넣으면 저장해 두고 똑같이 쓸 수 있어요.

# AI 숏드라마 전자책 (`ebook/`)

〈NOT YOUR MUSE〉 1화를 Claude 세션과 Higgsfield로 만든 기록을 바탕으로 쓴 제작 가이드 전자책. 초안 v0.1. 주소: `https://sogalbi.github.io/mani/ebook/`

- `ebook/index.html` 한 벌이 책 전체예요. 14장 구성(왜·무엇을 → 얼굴과 공간 고정 → 대본에서 영상으로 → 완성 → 시스템 → 부록).
- 노란 📌 상자는 아직 넣을 자료(스틸, 캡처, 숫자)가 필요한 자리, 초록 상자는 각 장 끝의 "Claude 세션에 이렇게" 프롬프트 틀, 보라 상자는 제작에서 나온 교훈이에요.
- PDF로 뽑기: `node ebook/build_pdf.js` → `ebook/ai-short-drama-ebook.pdf` (Playwright + Chromium 필요).
- 사실 관계는 제작 로그(STATUS_CHECKLIST, VIDEO_TEST_LOG, EP01_SCENE_PLAN 등) 기준이고, 크레딧 숫자는 근사치예요.
