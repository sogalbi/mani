# 워터마크 컷

레드노트(小红书)에서 다시 받은 내 사진의 맨 아래 워터마크 줄을 잘라 주는 폰용 웹앱.

- `index.html` 하나로 동작해요. 서버도, 설치도 필요 없고 사진은 기기 안에서만 처리돼요.
- 기본값은 짧은 변의 8.5%(1440px 사진이면 아래 122px)를 잘라요. 레드노트 워터마크(로고 + `rednote 아이디`)가 모두 들어가는 높이예요.
- 슬라이더와 ± 버튼으로 높이를 조절하고, "워터마크 확대"로 오른쪽 아래를 크게 보며 확인할 수 있어요.
- "원래 비율 유지"를 켜면 양옆도 같이 잘라서 3:4 같은 원래 비율을 지켜요.
- 결과는 JPEG(품질 95%)로, PNG는 PNG로 저장해요. 파일 이름 끝에 `_crop`이 붙어요.

폰 브라우저에서 열면 "저장"이 공유 시트로 열리고, 거기서 "이미지 저장"을 누르면 사진첩에 들어가요.
