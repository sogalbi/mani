## 드립 카드 (`card/`)

흰 바탕에 큰 제목, 그 아래 스레드 글 캡처처럼 `프로필 · 아이디 › 주제`와 본문이 들어간 인스타용 이미지를 만들어요.

- 큰 제목·아이디·주제·본문·회색 상자를 쓰면 위 미리보기가 바로 바뀌어요. 제목과 회색 상자는 비워도 돼요.
- 본문은 쓴 그대로 줄이 바뀌고, 빈 줄은 문단 사이 간격이 돼요. `ㄴ`, `1.`, `>`로 시작하는 줄은 길어져도 그 뒤에 맞춰 들여써져요.
- 비율은 3:4(1080×1440), 4:5(1080×1350), 1:1(1080×1080). 3:4가 프로필 격자에서 잘리지 않아요.
- 글이 길면 카드 안에 다 들어가게 글씨를 알아서 줄여요. 그래도 넘치면 미리보기 아래에 알려 줘요.
- `{쪽}`처럼 중괄호로 감싼 글자는 카드에서 모자이크돼요. 제목·본문·회색 상자 어디서든 돼요.
- **자동으로 쓰기**(Claude 앱에서 열었을 때만): 있었던 일을 대충 쓰거나 비워 두고 누르면 Claude가 큰 제목·주제·본문을 채워 줘요. GitHub Pages 주소로 열면 이 칸은 안 보여요.
- 프로필 사진과 아이디, 쓰던 글은 그 폰 브라우저에만 저장돼요.
- 저장은 PNG. 안드로이드는 갤러리 Download 앨범으로, 아이폰은 공유 시트("이미지 저장" 또는 인스타그램)로 가요. 안드로이드에서는 "공유" 버튼으로 인스타에 바로 보낼 수도 있어요.

## 워터마크 컷 (루트 `index.html`)

레드노트(小红书)에서 다시 받은 내 사진의 맨 아래 워터마크 줄을 잘라 주는 폰용 웹앱.

- `index.html` 하나로 동작해요. 서버도, 설치도 필요 없고 사진은 기기 안에서만 처리돼요.
- 기본값은 짧은 변의 8.5%(1440×1920 사진이면 아래 약 128px)를 잘라요. 레드노트 워터마크(로고 + `rednote 아이디`)가 모두 들어가는 높이예요.
- 슬라이더와 ± 버튼으로 높이를 조절하고, "워터마크 확대"로 오른쪽 아래를 크게 보며 확인할 수 있어요.
- 사진 고르기 창이 안 열리면 사진 앱에서 사진을 복사한 뒤 붙여넣기 칸에 붙여넣어도 돼요.

### 화질

- 일반 JPEG는 **다시 압축하지 않고** 잘라요. 압축된 데이터를 16px 줄 단위로 그대로 복사하고 높이 값만 바꾸는 방식이라, 남는 부분은 원본과 같은 데이터예요. 그래서 자르는 높이가 16px 단위로 맞춰져요.
- 이때 EXIF(원본 썸네일 포함), HDR 게인맵처럼 잘리기 전 모습이 남는 정보는 빼고, 색 프로필은 남겨요.
- PNG는 PNG로 저장해서 화질이 그대로예요.
- "원래 비율 유지"를 켰을 때나 프로그레시브 JPEG·HEIC·WebP 같은 파일은 품질 97% JPEG로 다시 압축해요.

## 폰 앱처럼 쓰기 (GitHub Pages, 두 앱 공통)

한 번만 켜 두면 Claude 없이 `https://sogalbi.github.io/mani/`(워터마크 컷), `https://sogalbi.github.io/mani/card/`(드립 카드)로 바로 열려요.

1. 폰 브라우저에서 `github.com/sogalbi/mani/settings/pages` 열기
2. Build and deployment → Source: **Deploy from a branch**
3. Branch: **ccr-bc37d147-85gn25**, 폴더 **/ (root)** → **Save**
4. 1~2분 뒤 주소를 열고 Chrome 메뉴(⋮) → **홈 화면에 추가**(또는 **앱 설치**). 드립 카드는 `/card/` 주소에서 따로 추가하면 아이콘이 따로 생겨요

저장하면 안드로이드는 갤러리의 Download 앨범으로, 아이폰은 공유 시트의 "이미지 저장"으로 사진첩에 들어가요.
