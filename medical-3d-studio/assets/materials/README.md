# 재질·색 기준

값은 `config/style.yaml` 의 `colors` 에 있고, `blender/scripts/m3d/materials.py` 가 그대로 씁니다.

| 구조 | 색 | 이유 |
|---|---|---|
| 혈관 안쪽 면 | 붉은 분홍 `#d9645f` | 혈관임을 바로 알아보게 |
| 잘린 단면 | 밝은 분홍 → 진한 빨강 → 살구색 띠 | 내막·중막·외막을 단순화한 층 |
| 플라크 단면 | 밝은 노랑 `#f8df92` | 좁아진 모양(모래시계)이 잘 보이게 가장 밝게 |
| 플라크 뒤쪽 면 | 어두운 황토 `#c98d3a` | 단면과 구분 |
| 스텐트 | 은색 금속 | 특정 제품 색이 아닌 일반 금속 |
| 풍선 | 반투명 하늘색 (alpha 0.32) | 뒤의 플라크·스텐트가 비쳐 보이게 |
| 혈구 | 진한 빨강 | 크기·속도는 실제 비율이 아님 (개념) |
| 배경 | 짙은 남색 `#0e1626` | 구조물 대비, 충격적이지 않은 차분한 톤 |

수술 장면처럼 보이는 피·조직 손상 표현은 쓰지 않습니다 (유튜브 폭력적·충격적 콘텐츠 정책, 광고 친화성).
