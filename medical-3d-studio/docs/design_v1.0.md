# MEDICAL 3D SHORTS STUDIO v1.0

## 확정 운영 조건
- 한국어 일반 시청자 대상
- 교육용 단순화 3D, 세로 9:16, 30~60초
- AI 사전 검증 + 관련 분야 의료 전문가 2단계 승인
- 의료 교육용 원리 설명, 개별 환자 진단·치료 지시 금지
- 1편 검증 → 10편 파일럿 → 300편 확장

## 1. 설계 원칙
1. 근거 추적: 핵심 주장마다 문헌 ID, 인용 위치, 확인일, 적용 범위 연결.
2. 교육적 단순화: 시술 원리만 표현하고 실제 수술 수행 매뉴얼로 오해될 세부 조작값은 생략.
3. 시각 정확성: 단순화된 모델이라도 구조 위치, 기구 역할, 전후 상태는 실제 의학과 일치.
4. 인간 승인: 의료 전문가의 근거·대본 승인과 최종 영상 승인 없이 게시 금지.
5. 권리 추적: 논문 이미지, 3D 메시, 폰트, 음악, 음성, 로고 등의 라이선스를 각각 기록.
6. 정정 가능성: 게시 후 이의제기, 오류 수정, 비공개 전환, 재검토 이력을 관리.
7. 자동 생성과 자동 게시 분리: 자동화는 조사·초안·렌더까지만, 게시에는 승인 게이트.

## 3. 단계별 승인 게이트
- G0 주제 승인: 교육 목적, 시청자, 민감도, 제작 적합성.
- G1 근거 승인: 의료 전문가가 핵심 주장, 출처, 대본 범위 검토.
- G2 자산 승인: 상업적 이용 권리, 저작자 표시, 출처, 정확도.
- G3 프리뷰 승인: 의료 전문가가 실제 3D 움직임, 단면, 자막, 음성을 확인.
- G4 게시 승인: 정책·법률·권리·광고·설명란·표시 점검.
- G5 게시 후 감시: 오류 제보와 업데이트에 따라 수정·비공개·재검수.

### 승인 결과 코드
PASS / REVISE / BLOCK / UNKNOWN. UNKNOWN은 PASS로 처리하지 않는다. 변경된 대본이나 장면은 관련 게이트를 다시 통과해야 한다.

## 4. 필수 의료 검수 체크리스트
- [ ] 영상이 다루는 질병·시술·대상과 제외 범위 명확
- [ ] 주요 주장별 검증 가능한 출처, 확인일, 연구 종류 기록
- [ ] 최신 가이드라인과 불일치 여부 확인
- [ ] 치료 결과·효과·성공률 과장 없음
- [ ] 환자별 적응증 차이와 불확실성 표현
- [ ] 해부학 위치, 비율, 기구 역할, 시술 전후 순서 적합
- [ ] 개념적 혈류·변형 표현을 실제 시뮬레이션으로 오인시키지 않음
- [ ] 대본·자막·음성·3D가 동일한 내용을 전달
- [ ] 전문가 성명/전문과목/검수일/검수 버전 내부 기록
- [ ] 전문가가 실제 확인한 범위만 '검수'라고 표기

## 5. 권리·법률·플랫폼 검수
- [ ] 한국 의료법상 의료광고 해당 여부 검토. 특정 병원·의료인·시술 유인/홍보 또는 협찬이 있으면 법률 전문가 검토.
- [ ] 의료 전문가 검수가 의료광고 심의 면제나 법적 안전을 보장하지 않음을 명시.
- [ ] 논문 내용의 사실 설명과 논문 도표·사진의 복제는 별개로 판단.
- [ ] 3D 모델·텍스처·폰트·배경음·AI 음성·효과음의 상업 이용권 확인.
- [ ] 저작자 표시, 수정 허용, 2차 저작물 조건 확인.
- [ ] 유튜브 의료 허위정보 정책, 폭력적/충격적 장면 정책, 광고 친화성, 반복 콘텐츠 수익화 정책, 합성·변형 콘텐츠 공개 의무 확인.
- [ ] AI 사용 사실만으로 저작권이 자동 발생한다고 단정하지 않음. 인간의 창작적 기여 및 권리 관계 기록.
- [ ] 환자 사진·검사 자료 사용 시 개인정보 및 동의 별도 검토.
- [ ] 의료 자문은 환자 개인에 대한 진단이나 치료 권고가 아님을 설명.
- [ ] 신고·정정 요청 수신 경로 마련.

## 6. Blender 제작 엔진
### 자산 라이브러리
- `anatomy/`: 심장, 관상동맥, 혈관벽, 장기별 교육용 기본 모델
- `pathology/`: 플라크, 협착 등 병리 상태(개념 모델)
- `devices/`: 스텐트, 풍선, 카테터의 일반화된 교육용 모델
- `materials/`: 조직/혈액/기구 색상 및 가독성 기준
- `camera_presets/`: 단면, 줌인, 회전, 비교 화면
- `motion_presets/`: Shape Keys, Curve Follow Path, Geometry Nodes
- `captions/`: 한국어 자막 템플릿

### 장면 명세 예시
```json
{
  "shot_id": "S04",
  "start_sec": 14,
  "end_sec": 24,
  "claim_ids": ["C03"],
  "assets": ["artery_cutaway_v1", "stent_generic_v1", "balloon_v1"],
  "action": "educational_expansion_visualization",
  "camera": "fixed_cutaway_closeup",
  "disclaimer": "교육용 개념도",
  "medical_review": "PENDING"
}
```

### 출력
- 마스터 .blend 파일, 샷별 .blend 또는 컬렉션
- 540×960 프리뷰 → 승인 후 1080×1920 최종
- 30fps, H.264 MP4, 자막/음성 별도 원본 보관
- 생성 스크립트와 자산 버전, 렌더 설정 기록

## 7. 첫 파일럿: 관상동맥 스텐트 원리
| 초 | 교육용 장면 | 핵심 메시지 |
|---|---|---|
| 0–3 | 좁아진 혈관 단면 | '심장 혈관이 좁아지면?' |
| 3–9 | 플라크와 내강 비교 | '혈액이 흐를 공간이 줄어듭니다.' |
| 9–15 | 시술 도구의 개념적 접근 | '의료진은 영상 장비를 보며 치료합니다.' |
| 15–25 | 풍선과 스텐트 확장 | '스텐트가 혈관 안쪽을 지지합니다.' |
| 25–32 | 풍선 제거, 스텐트 잔류 | '풍선은 빠지고 스텐트는 남습니다.' |
| 32–37 | 전후 내강 비교 | '좁아진 통로를 넓히는 원리입니다.' |
| 37–40 | 핵심 정리 | '교육용 3D 개념도. 환자마다 치료가 다릅니다.' |

의학적 주장·장면은 모두 전문가 검수 전 초안이다. 스텐트가 플라크를 제거하는 것으로 표현하지 않는다. 모든 협착이 스텐트 치료 대상인 것처럼 묘사하지 않는다.

## 8. 프로젝트 폴더
```
medical-3d-studio/
  config/                 # 채널·스타일·정책 설정
  research/               # 출처·근거·검토일
  topics/                 # 주제별 패키지
  assets/                 # 버전 관리되는 3D 자산
  blender/scripts/        # bpy 자동 생성·렌더
  blender/scenes/         # .blend 프로젝트
  renders/preview/        # 전문가 검수용
  renders/final/          # 승인된 완성본
  reviews/medical/        # 서명·의견·수정 이력
  reviews/legal_policy/   # 저작권·정책 체크
  publishing/             # 제목·설명·썸네일
  analytics/              # 성과·오류·정정
```

## 9. 데이터 스키마
- `topics`: topic_id, subject, risk_level, status, duplicate_score
- `sources`: source_id, title, authors, year, doi, pmid, url, access_level, checked_at
- `claims`: claim_id, statement, source_ids, confidence, limitations, reviewer_status
- `assets`: asset_id, source_url, license, commercial_use, attribution, version, accuracy_status
- `shots`: shot_id, timecode, claim_ids, assets, animation, review_status
- `approvals`: gate, reviewer, role, timestamp, version_hash, decision, comments
- `videos`: video_id, script_version, render_version, upload_status, published_url
- `corrections`: ticket_id, severity, report, action, reviewer, resolved_at

## 10. 중단 규칙
- 근거 미확인·상충 주장 → 연구 단계 보류
- 의료 전문가가 정확성 반려 → 대본/3D 수정 후 재검수
- 라이선스 불명 → 해당 자산 대체 또는 권리 확인 전 사용 금지
- 병원 협찬/치료 권유 → 의료광고 법률 검토 전 보류
- 게시 후 중대한 의료 오류 제보 → 임시 비공개 검토, 전문가 재검증, 수정·정정 기록

## 11. 개발 로드맵
1. **MVP 1편**: 수동 근거 수집 + 자동 장면 조립 + 전문가 검수 + 수동 게시.
2. **10편 파일럿**: 심장·혈관 자산 재사용, 오류율/제작 시간/검수 시간/유지율 측정.
3. **50편 운영**: 주제 큐, 데이터베이스, 검수 대시보드, 버전 잠금.
4. **300편 확장**: 분야별 자산 팩, 검색 자동화, 재검토 일정, 정정 워크플로.

## 12. 아직 결정해야 할 사항
- 실제 검수 의료 전문가 확보와 계약 범위·보수·책임
- 사용할 해부학 모델의 출처와 상업 라이선스
- 영상마다 출처를 표시할 방식(설명란 + 내부 근거표)
- 의료광고/협찬 수용 여부와 법률 자문 체계
- 서버 렌더 비용과 월간 제작량
- 정책 업데이트를 점검할 주기

**현재 상태:** 실행 가능한 제작 설계 문서이며, 실제 의료 검수·법률 검토·3D 제작·게시 승인이 완료된 것은 아니다.
