# 점수표

생성할 때마다 한 줄씩 추가합니다. 점수는 `score.py`로 계산합니다.

```
python playbook/score.py <원본> <생성본> <원본에서의 시작 초> "<쇼트 경계, 구간 기준 초>" --json out.json
```

**점수 구성 (100점)**: 컷 일치 25 + 타이밍 15 + 전환 방식 15 + 색 25 + 움직임 20

- 컷 일치: 원본 쇼트 경계마다 0.25초 안에 하드컷이나 블러 전환이 있는지. 불필요한 하드컷은 감점
- 타이밍: 일치한 컷의 평균 시간 오차
- 전환 방식: 원본의 블러 전환(휙 넘어가기, 줌 블러)이 같은 시각에 있는지
- 색: 쇼트별 밝기·채도·따뜻함 차이
- 움직임: 쇼트별 화면 움직임 양의 비율

**사람 평가**

- 시도 1: 장면 순서와 구도는 따라왔다. 색이 차갑고, 전환이 전부 하드컷이라 느리게 느껴진다. 얼굴이 다 나오고 태블릿이 크다. 건물이 붉은 벽돌로 나왔다(프롬프트 오류).
- 시도 2: 눈으로 보면 1보다 확실히 원본에 가깝다. 베이지 톤, 세 번 끊어 들어가는 도입, 얼굴 잘림, 한 손 태블릿, 흰 소매, 블러 전환 2곳이 재현됐다. 남은 문제는 다음과 같다.
  - 쇼트 5(8.8초)에서 태블릿이 세로로 바뀌지 않아 컷이 빠졌다
  - 자동차 거리와 트램 광장이 한 장소로 합쳐졌다
  - 원본보다 밝고 더 따뜻하다
  - 도입의 두 번째 확대(1.3초)가 블러 없이 들어갔다
  - 컷 시각을 당긴 탓에 컷이 전부 조금 이르다

**다음 시도에서 바꿀 것**: 컷 시각을 원본 그대로 되돌린다. "bright"를 빼고 밝기를 낮춘다. 쇼트 4를 두 장소로 명확히 나눈다. 쇼트 5의 세로 전환을 더 크게 적는다.
