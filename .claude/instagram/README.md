# 인스타 작업 준비

출처: 프롬왓 노션 글 「클로드 인스타 스킬 13개 설치·사용법 모음집」(2026-11-09)과 그 원문 깃허브 저장소
[Jakeschincariol/instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill) (MIT, 무료, 2026-11-10 확인).

핵심 한 줄: **글은 스킬이 쓰고, 게시 버튼은 내가 누른다.** 자동 게시·자동 댓글·자동 팔로우는 일부러 없음(인스타 약관 위반으로 계정이 막힐 수 있어서). 모든 스킬은 "복사해서 붙여넣을 결과물"에서 멈춘다.

## 이 폴더

| 파일 | 역할 | 상태 |
| --- | --- | --- |
| `voice.md` | 내 말투 파일. **제일 먼저 채울 것.** 스킬 13개가 전부 읽는다. | 비어 있음 |
| `profile-ko.md` | 프로필 채점표 12개(100점) 한국어 + 내 프로필 적는 칸 | 칸 채우면 바로 채점 가능 |
| `hooks-ko.md` | 첫 3초 문구 공식 26개 한국어 표 + 점수기·구성표가 보는 기준 | 완성 |
| `viral-ko.md` | 터진 릴스 조사 순서(계정 고르기 → 적기 → 순위) | 완성 |
| `swipe-capture.tsv` | 조사하며 적는 표. 예시 한 줄 들어 있음 | 조사하면서 채움 |
| `ai-tells-ko.md` | 한국어 AI 상투어·구조 목록(영어 도구 보조) | 완성 |
| `plan.md` | 주간 계획 틀. `/ig-plan`이 채움 | 틀만 |
| `log.md` | 올린 기록·댓글 단 계정. 스킬이 "올렸어?"에 예라고 하면 적음 | 틀만 |
| `swipe.md` | `/ig-viral`이 만드는 잘된 릴스 순위표 | 아직 없음 |

스킬 원문은 `~/.claude/instagram/` 경로를 말하는데, 클라우드 세션에서는 홈 폴더가 남지 않으니 이 레포의 `.claude/instagram/` 을 대신 쓴다(`CLAUDE.md`에 적어 둠).

## 설치 전에 지금 바로 할 수 있는 것

1. `voice.md` 채우기. 직접 쓰거나, 내 릴스·캡션 3개를 붙여넣고 "이걸로 voice.md 채워 줘".
2. `profile-ko.md` 아래 "내 프로필" 칸에 인스타 프로필 편집 화면을 그대로 복사해 넣기. 그러면 스킬 없이도 채점할 수 있다.
3. `viral-ko.md` 1번 표에 볼 계정 6~12곳 적기.
4. 릴스 아이디어가 있으면 `hooks-ko.md` 표에서 맞는 공식 3개를 고르고 후보 문구를 써 보기. 점수는 설치 뒤 `hookscore.py`로.

## 설치 (아직 안 됨 — 사람이 한 번 승인해야 함)

클로드 코드에서 둘 중 하나:

```
/plugin marketplace add Jakeschincariol/instagram-agent-skill
/plugin install instagram-agent
```

또는 레포 안에 직접 넣기(이 레포 세션에서만 쓰려면 이쪽):

```bash
git clone --depth 1 https://github.com/Jakeschincariol/instagram-agent-skill /tmp/igskill
mkdir -p .claude/skills
cp -r /tmp/igskill/skills/ig-* .claude/skills/
cp /tmp/igskill/LICENSE .claude/skills/LICENSE-instagram-agent-skill
```

설치되면 `/ig-reel` 쳐서 되는지 확인.

## 바로 붙여넣을 요청 (노션 글 그대로)

**말투 파일부터**
```
내가 올린 릴스 3개의 대본(또는 자막)을 붙여넣을게.
이걸 보고 .claude/instagram/voice.md 를 채워 줘.
내가 자주 쓰는 말버릇, 문장 길이, 절대 안 쓰는 표현을 따로 정리해 줘.
```

**1. 프로필 채점**
```
내 인스타 프로필을 채점해 줘. 이름 칸: (이름 칸 그대로)
소개 글: (소개 글 그대로) / 링크: (링크) / 고정 게시물 3개 제목: (제목들)
깎인 점수가 큰 순서대로 고친 문장을 같이 보여 줘.
```

**2. 터진 릴스 찾기**
```
내 분야는 (예: 홈카페 레시피)야. 비슷한 계정 10곳을 같이 정하고,
각 계정의 최근 릴스에서 평소보다 몇 배 잘된 것만 골라 순위를 매겨 줘.
잘된 릴스마다 어떤 첫 3초 공식을 썼는지 이름을 붙여서 스와이프 파일로 저장해 줘.
```

**3. 릴스 대본**
```
아이디어: (예: 협업 계약서에서 꼭 넣어야 하는 한 줄)
목표 길이 30초. 첫 3초 문구 후보 3개를 점수와 함께 보여 주고,
가장 높은 문구로 대본, 화면 자막, 초 단위 구성표까지 만들어 줘.
```

**4. 캡션 검사**
```
아래 캡션을 검사해 줘. 검색에 걸려야 하는 말: (예: 홈카페, 라떼아트)
첫 줄이 125자 안에서 끝나는지, 해시태그가 5개 이하인지 확인하고
걸린 항목은 고친 문장을 같이 줘.
(캡션 붙여넣기)
```

**5. AI 티 지우기**
```
아래 초안에서 AI 티 나는 부분을 지우고, 바꾼 곳을 전부 보여 줘.
문장 구조를 바꿔야 하는 곳은 고치지 말고 표시만 해 줘.
마지막에 고치기 전과 후 사람 점수를 비교해 줘.
(초안 붙여넣기)
```

**6. DM**
```
내 게시물에 '자료'라고 댓글 단 사람에게 보낼 DM을 써 줘.
보낼 자료: (링크와 자료 이름)
협업 제안 문구 1개와, 답이 없을 때 보낼 후속 메시지 2개도 같이 준비해 줘.
```

**나머지 7개 한 줄 요청**
- `/ig-plan` 「이번 주 업로드 계획 짜 줘. 릴스 3개, 캐러셀 2개 기준」
- `/ig-carousel` 「이 주제로 7장 캐러셀 문구와 표지 3안 줘」
- `/ig-story` 「오늘 스토리 5장 순서와 넣을 스티커 정해 줘」
- `/ig-comment` 「이 게시물에 달 댓글 2개 써 줘」
- `/ig-reply` 「이 댓글 목록 분류하고 답글 써 줘」
- `/ig-repurpose` 「이 유튜브 대본으로 일주일 치 릴스 5개 뽑아 줘」
- `/ig-audit` 「지난달 게시물 성적표 만들어 줘」

## 알고 쓸 것 (만든 사람이 직접 밝힌 한계)

- 첫 3초 점수기는 **나쁜 문구 거르기**에는 잘 맞지만(AUC 0.83), 괜찮은 문구 둘 중 어느 게 터질지는 **동전 던지기 수준**(AUC 0.56). 찍기 전 버릴 문구 고르는 용도로만.
- 공식 분류기는 실제 말의 49%만 알아봄. 나머지는 "분류 안 함"으로 둠.
- 해시태그 한도는 2025-12-18부터 **5개**. 인스타 화면과 다르면 인스타가 맞음.
- 측정 자료는 릴스가 아니라 유튜브 쇼츠 74개(인스타는 로그인 없이 조회수를 못 받아서).
- 파이썬 도구 5개(`hookscore.py`, `beats.py`, `caption.py`, `humanize.py`, `detect.py`)는 표준 라이브러리만 쓰고 네트워크 없음. 2026-11-10에 코드 확인함. `--out`을 줄 때만 파일을 씀.
- `/ig-viral`은 내 브라우저로 계정 10곳을 사람 속도로 둘러보는 방식. 비밀번호 안 물음, 대량 수집 아님.
