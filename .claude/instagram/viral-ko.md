# 터진 릴스 조사 (/ig-viral) 준비

스킬이 하는 일은 **조회수가 아니라 "평소 대비 배수"로 줄 세우기**다. 배수 = 이 릴스 조회수 ÷ 그 계정 최근 릴스 12개의 중앙값. 3배 넘으면 신호, 1.5배 아래면 그 계정의 평범한 날이라 배울 게 없다.
한 달에 한 번이면 된다. 공식은 한 시즌 간다.

## 1. 계정 고르기 (6~12곳, 내 규모의 10배 이내)

| 구분 | 수 | 기준 | 내 후보 |
| --- | --- | --- | --- |
| 직접 | 4 | 같은 분야, 같은 제안, 나보다 조금 앞 | |
| 인접 | 4 | 다른 분야, 같은 시청자. 형식은 여기서 먼저 빌려 옴 | |
| 큰 계정 | 2~4 | 훨씬 큰 계정. 형식만 참고, 주기·말투는 참고 안 함 | |

내 **저장됨 컬렉션**도 연다. 이미 내 취향으로 걸러진 가장 빠른 자료다.

## 2. 보기 (읽기지 긁기 아님)

- 내 브라우저에서 내가 로그인한 채로, 사람 속도로. 계정 10곳 × 릴스 12개 정도.
- 비밀번호 안 알려 줌, 자동 수집 안 함, 백그라운드 반복 안 함.
- 베끼는 건 **공식**이지 영상이 아님. 훅 모양, 구조, 길이, 컷 패턴. 대본·말투·편집은 아님. 모든 줄에 출처 계정을 적는다.

릴스마다 적을 것(만든 사람 말 그대로):

| 칸 | 메모 |
| --- | --- |
| account | 아이디 |
| followers | 프로필의 팔로워 수 |
| median | 최근 릴스 12개를 훑어 중간 조회수 |
| views | 이 릴스 조회수 |
| hook | 첫 줄, 말이든 자막이든 문법 틀린 것까지 그대로 |
| on-screen | 첫 자막 카드(다르면) |
| length | 초 |
| cta | 마지막에 뭘 해 달라고 했는지 |

**median이 제일 중요하다.** 없으면 팔로워 수로 줄 세우는 꼴로 돌아간다.

## 3. 파일에 적기

`swipe-capture.tsv`에 탭으로 구분해 적는다(엑셀·시트에서 적고 TSV로 내보내도 됨). 설치 뒤 이 명령으로 순위표가 나온다:

```bash
python3 .claude/skills/ig-viral/swipe.py .claude/instagram/swipe-capture.tsv --out .claude/instagram/swipe.md
```

## 4. 보고할 것 셋만

1. 상위 1/3에서 **어떤 공식이 반복**되는지, 횟수와 함께. 계정 6곳에서 4번씩 나오면 발견, 2번이면 아님.
2. 상위 1/3이 하위와 **구조적으로 다른 점**: 훅 길이, 결과가 눈에 보이는지, 첫 프레임이 움직이는지, 요청이 어디 있는지.
3. **분류 안 된 줄.** 공식표에 없는 새 모양이거나 소음. 손으로 읽을 것. 가장 가치 있는 칸.

표본 크기와 확신을 말로 적는다. 계정 6곳 릴스 40개면 주장이 되고, 12개면 안 된다.

## 5. 찍을 것으로 바꾸기

상위 공식 3개로 **내 버전** 훅 한 줄씩. 내 이야기, 내 숫자, 잘되는 모양으로. "이거 같은 릴스 만들어"가 아니라 내일 말할 수 있는 첫 문장.
