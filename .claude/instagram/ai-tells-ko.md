# 한국어 AI 티 목록 (/ig-human 보조)

스킬의 humanize.py는 영어 상투어 154개를 지운다. 한국어 캡션에는 자동으로 안 걸리니, 이 목록을 함께 쓴다. 초안을 쓴 뒤 아래를 훑어 **지우거나(자동 가능) 표시해서 내 말로 다시 쓴다(판단 필요).**

## 바로 지우는 것

- **보이지 않는 문자**: 폭 0 공백, 결합 문자, BOM, 줄 바꿈 안 되는 공백. 키보드로는 안 생김. humanize.py가 한국어 글에서도 잡는다.
- **긴 줄표(—, –)** → 쉼표나 마침표로. 한국어 캡션에서 긴 줄표는 거의 AI 표식.
- **둥근 따옴표(“ ” ‘ ’)** → 곧은 따옴표(" ')나 낫표(「 」).
- **줄임표(…)** → 점 세 개(...)나 없앰.

## 표시만 하는 것 (구조라 직접 다시 쓰기)

- "단순히 A가 아니라 B입니다" 꼴
- 셋씩 짝지은 나열("A, B, 그리고 C")이 문단마다 나옴
- 영상 서론 인사("안녕하세요, 오늘은…")
- 이모지로 시작하는 글머리표 목록
- 해시태그 벽(한도 5개)
- 문장 길이가 다 비슷함(짧은 문장과 긴 문장이 섞여야 사람 글)
- 모든 문장이 "~요"로 끝남 → "~다", 명사형, 물음표를 섞기
- 느낌표가 문장마다 있음

## 사람 점수 다섯 항목 (detect.py가 보는 것)

1. **들쭉날쭉함** — 문장 길이가 다양한가
2. **구체성** — 100단어당 숫자·이름·고유한 것이 몇 개
3. **상투어 밀도** — 위 목록 같은 말이 100단어당 몇 개
4. **지문** — 긴 줄표, 둥근 따옴표, 보이지 않는 문자
5. **말투 흔적** — 위 "표시만 하는 것" 구조가 몇 개

영어 기준으로 짠 도구라 한국어 점수는 참고만. 한국어에서 실제로 믿을 건 2(구체성)와 4(지문)다.
